// Clinic Booking System

A lightweight, serverless web application designed for booking clinic appointments online. Built with a responsive frontend hosted on GitHub Pages and backed by Firebase Firestore for real-time appointment management.



//Features

- Online Appointment Booking: Patients can easily pick a department, select a preferred date and time, and submit their contact details.
- Real-Time Data Storage: Instantly saves appointments directly to a cloud database (Firebase Firestore).
- Fully Responsive UI: Optimized for seamless viewing on desktops, tablets, and mobile devices.
- Zero Server Overhead: Built using a serverless architecture, hosted completely free.



//Tech Stack

* Frontend: HTML5, CSS3, JavaScript (ES6 Modules)
* Backend & Database: Firebase Cloud Firestore
* Hosting: GitHub Pages
